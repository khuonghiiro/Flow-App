# Coding & Modularity Standards for AI Studio & Flow-App

1. **File Size Limit**:
   - Target: 200 – 600 lines per file.
   - Hard limit: 800 – 1000 lines.
   - Always decompose large UI views and multi-tab modals into subcomponents in dedicated feature folders.

2. **Method Size Limit**:
   - Keep functions and methods under 50 – 80 lines.

3. **UI Layout Standards**:
   - For character creation / customizers: Column 1 = 3D / 2D Viewport with Character Equipment Slots (RPG style); Column 2 = Material Catalog & Structure Tuning Sliders.
