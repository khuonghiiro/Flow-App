# 🎵 THƯ MỤC ÂM THANH TỔNG HỢP (AUDIO ROOT)

---

## 📌 1. Mục Đích & Vai Trò (Purpose)
Chứa toàn bộ các thành phần âm thanh của bộ phim:
- **`bgm/`**: Nhạc nền tổng thể (Background Music) tạo không khí cho cảnh quay.
- **`sfx/`**: Tiếng động hiệu ứng (Sound Effects) như chém kiếm, bước chân, gió rít, nổ phép.
- **`dialogues/`**: Các file âm thanh giọng đọc thoại được xuất ra tự động bởi hệ thống Text-to-Speech (TTS).

---

## 📂 2. Cấu Trúc Chi Tiết
```text
assets/audio/
├── bgm/         # Nhạc nền (.mp3, .wav)
├── sfx/         # Hiệu ứng âm thanh (.mp3, .wav)
└── dialogues/   # File giọng đọc từng câu thoại ({scene_id}_{speaker_id}_{line_id}.mp3)
```
