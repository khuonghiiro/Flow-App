# ASSET DIRECTORY — AI 3D Animation Studio

> **FOR AI AGENTS:** This file is the main reference for understanding the asset structure.
> When generating JSON scene configs, AI must read `ASSET_CATALOG.md` in this folder for available resources.
> Vietnamese version for users: `README_VI.md`

---

## 1. Purpose

The `assets/` directory contains all input resources (3D models, textures, audio, animations, maps) for the AI Animation Studio.

- **For Users:** Drop character models, props, sounds, animations, or maps into the corresponding subfolders.
- **For AI Agents:** Scan this directory to discover available characters, maps, weapons, VFX, and generate scene configs accordingly.

---

## 2. Folder Structure

```text
assets/
├── ASSET_CATALOG.md             # Auto-generated by _scan_assets.bat (AI reads this)
├── ASSET_CATALOG_VI.md          # Auto-generated Vietnamese version (User reads this)
├── asset_manifest.json          # Machine-readable JSON catalog
├── characters/
│   ├── base_bodies/             # Base body skeletons (.vrm, .glb)
│   ├── faces/                   # Modular face meshes (.glb)
│   ├── hairstyles/              # Hair meshes (.glb)
│   ├── beards/                  # Beard meshes (.glb)
│   ├── costumes/                # Costume/clothing meshes (.glb)
│   └── accessories/             # Accessory meshes (.glb)
├── props/
│   ├── weapons/                 # Weapons (.glb)
│   ├── tools/                   # Interaction tools (.glb)
│   ├── consumables/             # Consumable items (.glb)
│   ├── furniture/               # Interactive furniture (.glb)
│   ├── buildings/               # Buildings with upgrade levels (.glb)
│   ├── nature/                  # Trees, rocks, bushes (.glb)
│   └── vehicles/                # Mounts, flying swords, clouds (.glb)
├── maps/                        # Environment maps (.glb, .gltf)
├── audio/
│   ├── bgm/                     # Background music (.mp3, .wav)
│   ├── sfx/
│   │   ├── combat/              # Combat sound effects
│   │   ├── interaction/         # Interaction sound effects
│   │   └── ambient/             # Ambient environment sounds
│   └── dialogues/               # TTS voice dialogue files
├── animations/
│   ├── combat/                  # Combat animation clips (.glb, .bvh)
│   ├── interaction/             # Interaction animations
│   ├── xianxia/                 # Xianxia/cultivation pose animations
│   └── locomotion/              # Locomotion (walk, run, fly) animations
└── vfx/                         # VFX textures & sprites (.png)
```

## 3. AI Instructions — How to Use Assets

### Step 1: Scan resources
Run `_scan_assets.bat` to generate `ASSET_CATALOG.md` and `asset_manifest.json`.

### Step 2: Read the catalog
AI agents must read `ASSET_CATALOG.md` to know which assets are available, what actions/expressions are supported.

### Step 3: Generate JSON scene config
Based on the catalog, generate a valid `MasterSceneConfig` JSON file.

### File Naming Convention
- 3D Models: `{category}_{name}.glb` or `{name}.vrm`
- Audio: `sfx_{action}.mp3`, `bgm_{mood}.mp3`
- Animations: `anim_{action}.glb`
- Valid formats: `.vrm`, `.glb`, `.gltf` (3D) | `.mp3`, `.wav` (audio) | `.bvh`, `.fbx` (motion)

### Modular Character Assembly
Characters can be assembled from modular parts using the `assembly` field:
```json
{
  "assembly": {
    "base_body": "characters/base_bodies/male_warrior.vrm",
    "face": "characters/faces/face_male_young.glb",
    "hairstyle": "characters/hairstyles/hair_topknot.glb",
    "costume": "characters/costumes/costume_xianxia_white.glb",
    "accessories": ["characters/accessories/acc_crown_gold.glb"],
    "skin_color": "#ffd1b3",
    "hair_color": "#1a1a2e"
  }
}
```
If no individual `.glb` parts exist yet, use the legacy `model` field (backward compatible).

### ID Matching Rule
Each file ID is derived from the filename without extension.
Example: `characters/base_bodies/male_warrior.vrm` → ID = `male_warrior`
