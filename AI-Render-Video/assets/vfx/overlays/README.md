# SCREEN OVERLAYS — Animated Anime Speedlines & Impact Frames

## Purpose
Contains full-screen or camera-space animated GIF overlays for comic books, anime action scenes, and impact moments.

## Supported Presets
- \`speed_lines_burst.gif\` (Anime action lines converging to center)
- \`impact_lines_radial.gif\` (Manga heavy punch impact lines)
- \`lightning_frame.gif\` (Electric storm cinematic screen frame)

## AI Usage
Used in \`gif_overlays\` with \`"attach_to": "screen_overlay"\`.
