# BEARDS — Character Facial Hair

## Naming Convention
```
beard_{style}.glb
```
Examples: `beard_goatee.glb`, `beard_long_sage.glb`, `beard_stubble.glb`

## Technical Requirements
- Attach point: `head` bone (chin region).

## AI Usage
```json
{ "assembly": { "beard": "characters/beards/beard_long_sage.glb" } }
```
